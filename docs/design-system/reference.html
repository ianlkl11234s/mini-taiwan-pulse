元件與樣式參考

每個區塊都 import 實際元件與 token（src/design-system/），暗／淡並排；旁邊印出的數值是執行期讀到的真值。改了 token 或元件，這頁跟著變。

規格文件：UI docs/design-system/spec.md、地圖 docs/design-system/map-layers.md。標籤：真元件 直接渲染；結構仿製，樣式為真 元件本身會拉進資料載入鏈或只吃全域狀態，改用它的真 class／真 token 組出；文件值 程式沒有匯出常數，照規格印出。
