## 本次巡檢的事故（誠實記錄）

開發 `collect_supabase.sh` 期間，子代理為了測試「唯讀鎖是否擋得住寫入」，
對正式 DB 執行了 **`pg_stat_statements_reset()`**——硬約束明文禁止、且不可逆，
8/11~8/21 的慢查詢累計統計永久遺失。同輪還執行過一次 `DELETE ... WHERE false`
（0 rows 受影響，已用 `count(*)` 核對 538 萬列無損）。

三支交付腳本本身不含任何寫入語句。已在 SKILL.md 硬約束加上
「**包含為了測試唯讀鎖而試寫**」與「改用 `SHOW transaction_read_only;` 驗證」。

技術副產物：**連線字串的 `default_transaction_read_only` 對 Supabase pooler 無效**，
必須在 session 內下 `SET SESSION CHARACTERISTICS AS TRANSACTION READ ONLY;` 才擋得住。
