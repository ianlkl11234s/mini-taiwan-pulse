# CCTV 車輛標註規範與批次清單

更新：2026-10-02。搭配 [cctv-finetune-roadmap-2026-09-29.md](cctv-finetune-roadmap-2026-09-29.md)。規則有疑問時，先依本文件；遇到本文件沒寫到的情況，記下批次與張數再問，決定後補進第5節。

## 1. 每張畫面要做的事

框是電腦（yolo26m）先標的，**你的工作是讓每張畫面的框都正確**：

1. **改類別**：點框，按 `1` 汽車、`2` 機車、`3` 公車、`4` 貨車。
2. **刪除**：框到不是車的東西（行人、招牌、路燈反光、地面標線），點框後按 `Delete`。
3. **補框**：漏掉的車，先按類別鍵選好類別，再到空白處拖曳畫框。**機車漏掉最多，這是主要工作。**
4. **調整**：框太大或太小，拖曳四個角；位置偏了，拖曳框本身。
5. 確認整張都正確後，按「完成，下一張」。

## 2. 類別規則

| 類別 | 包含 | 不包含 |
|---|---|---|
| 汽車 `car` | 轎車、休旅車、計程車、小貨卡、廂型車 | — |
| 機車 `motorcycle` | 機車、速克達，**框要包住騎士加車身**；停放的機車也要標 | 腳踏車、行人 |
| 公車 `bus` | 公車、遊覽車、大型巴士 | 小巴（算汽車） |
| 貨車 `truck` | 大貨車、聯結車、垃圾車、工程車 | 小貨卡（算汽車） |

## 3. 框的規則

- **貼齊車輛可見的外緣**，不要留太多空白。
- **被遮住一部分**：只框看得到的部分。看不出是哪一類就不標。
- **太小**：高度小於約8像素，或你自己也看不出是車，就**不標也不刪**，保持原樣。訓練時會另外設定忽略的大小門檻。
- **畫面邊緣只露一小截**：露出不到一半，不標。
- **同一台車只有一個框**：發現兩個框重疊在同一台車上，刪掉一個。
- **夜間頭燈**：只看得到一團光，看不出車形，不標；看得出是機車（兩輪、單燈、有騎士），就標機車。

## 4. 批次清單與建議順序

伺服器：在 POC 目錄執行 `./start.sh`，然後開下列網址。每批做完按「下載結果 JSON」，檔名會是 `box-truth-<批次>.json`，交給 Claude 驗收。

| 順序 | 批次 | 用途 | 張數 | 網址 |
|---|---|---|---:|---|
| 1 | batch-001 | 訓練（含7張測試鏡頭） | 40 | `annotate.html?batch=batch-001` |
| 2 | batch-002-test | **測試**（中正路、經貿二路、西藏路） | 50 | `annotate.html?batch=batch-002-test` |
| 3 | batch-003-val | **驗證**（訓練鏡頭、10/1 的 03／08／14／20 時） | 47 | `annotate.html?batch=batch-003-val` |
| 4 | batch-004-train | 訓練 | 50 | `annotate.html?batch=batch-004-train` |
| 5 | batch-005-train | 訓練 | 50 | `annotate.html?batch=batch-005-train` |
| ── | **第一版訓練** | 訓練約133張、驗證47、測試57 | | |
| 6 | batch-006-test | 測試 | 50 | `annotate.html?batch=batch-006-test` |
| 7 | batch-007-train | 訓練 | 50 | `annotate.html?batch=batch-007-train` |
| 8 | batch-008-train | 訓練 | 50 | `annotate.html?batch=batch-008-train` |
| ── | **學習曲線** | 訓練約233張，比較25／50／100% | | |

為什麼先做測試和驗證：分數的「尺」要先固定，之後每一版模型才能公平比較。測試批次標完後就不要再回去改，除非發現明顯標錯；如果改了，要記錄下來。

## 6. 驗收方式

每批收到 JSON 後會檢查：
- 每張是否都按了「完成」。
- 改類別、刪除、新增的數量，以及每張的機車數。
- 抽幾張檢查框有沒有包住騎士、有沒有重複的框。
- 測試和驗證批次的分數，只拿來比較模型，不拿來調整標註。
