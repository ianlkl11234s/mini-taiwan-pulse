## 1. 三個新資料源真實樣本

### 1.1 TWSE 加權指數（即時 5 秒）

**狀態**：✅ 可用，盤中 09:00–13:30 每 5 秒更新

**端點**：`https://mis.twse.com.tw/stock/api/getStockInfo.jsp?ex_ch=tse_t00.tw|tse_IX0001.tw&json=1&delay=0`
**必帶 Header**：`Referer: https://mis.twse.com.tw/stock/index.jsp`

**真實樣本**（2026-06-12 收盤）：

```json
{
  "n": "發行量加權股價指數",
  "z": "44169.04",      // 當前指數
  "y": "43149.46",      // 昨日收盤
  "o": "43587.63",      // 開盤
  "h": "44798.88",      // 最高
  "l": "43587.63",      // 最低
  "t": "13:33:00",      // 最後時間
  "m": "12197113",      // 累計成交金額（千元）= 1.22 兆
  "r": "3541970"        // 累計成交量（張）
}
```

**算漲跌**：`z - y = +1019.58 (+2.36%)`

**設計要素**：
- 主數字「44,169」+ 漲跌「↑+1,019 +2.36%」（紅綠依台股慣例：漲紅跌綠）
- 副資訊：振幅 H/L、成交額「1.22 兆」
- 盤前 / 盤後 / 週末 → 顯示「收盤 / 休市」灰態
- ❌ **沒有** 上漲家數 / 下跌家數欄位（如需另接日報，但即時 widget 不需要）

**注意**：
- 非交易日仍回傳上一交易日值，靠 `d` 欄判斷 stale
- 官方建議 polling 5s，<3s 可能被擋

### 1.2 共機擾台（每日 06:00 UTC+8 結算）

**狀態**：✅ 可用，雙源並用

**主源**：Twitter / X `@MoNDefense`（每日 08–10 點發英文推文，格式公式化）
**備援**：MND 中文官網 `https://www.mnd.gov.tw/PublishTable.aspx?Types=即時軍事動態&title=國防消息`

**真實樣本**（@MoNDefense 推文）：

> "29 sorties of PLA aircraft, 7 PLAN vessels and 1 official ship operating around Taiwan detected up until 6 a.m. (UTC+8) today. **24 out of 29 sorties crossed the median line** and entered Taiwan's northern, central, southwestern and eastern part ADIZ."

**結構化欄位**：

| 欄位 | 值 | 說明 |
|---|---|---|
| `total_aircraft_sorties` | 29 | 軍機架次 |
| `plan_vessels` | 7 | 海軍艦艇 |
| `official_ships` | 1 | 公務船 |
| `crossed_median_line_count` | 24 | 越中線數 |
| `adiz_north` / `central` / `southwestern` / `eastern` | bool | 4 個 ADIZ 區域 |

**設計要素**：
- 大數字「**29**」架次 + 紅色徽章「24 越中線」
- 4 個 ADIZ 區域小燈號（北 / 中 / 西南 / 東）
- 用詞固定：「中共解放軍臺海周邊海、空域動態」（官方原文）
- 週末 / 和平期可能歸零 → UI 顯示「上午 8 點前更新」而非「無事件」

**⚠️ 政治敏感 disclaimer**：
- 不用「擾台」「侵擾」（民間 / 媒體用語）
- Footer 註「資料來源：中華民國國防部 @MoNDefense，每日 06:00 (UTC+8) 截止」
- 不自行解讀威脅等級

### 1.3 CDC 公衛週報（每週四發布上週資料）

**狀態**：✅ 可用，建議放 3 個疾病

**端點**：`https://data.cdc.gov.tw/`（CKAN API + CSV 直下載 `od.cdc.gov.tw/eic/*.csv`）

**⚠️ 必加 `verify=False`**（同 NHI 端點 SSL SKI 缺失問題）

**3 個推薦 dataset**：

| 名稱 | dataset_id | 頻率 |
|---|---|---|
| 類流感急診就診 | `rods-influenza` | 週 |
| 登革熱週確診（到鄉鎮） | `aagstable-weekly-dengue` | 週 |
| 腸病毒急診 | `rods-enteroviral-infection` | 週 |

**真實樣本**（最新 W22–W23）：

```csv
# 類流感 W22
年,週,年齡,縣市,就診數,縣市碼
2026,22,7~12,雲林縣,18,10009
2026,22,25~64,臺北市,124,63000

# 登革熱 W23（到鄉鎮）
年,週,縣市,鄉鎮,性別,境外,年齡,病例數,縣市碼,鄉鎮碼
061,2026,23,高雄市,鳳山區,F,0,70+,1,64000,64000120

# 腸病毒 W22
2026,22,7~15,臺北市,2,63000
```

**設計要素**：
- 3 個指標 KPI 卡並排：流感 / 登革熱 / 腸病毒
- 每張卡：當週數字 + **4 週 sparkline** + 跟去年同期 ↑↓ 比較
- 登革熱多一個 mini choropleth（縣市分布，可選）
- 標頭明示「截至 ISO 第 W{n} 週」（避免讓人以為即時）

## 3. 壓力指數設計參數

> 把 10 個 signals（電網 / 路況 / 急診 / 地震 / 災害示警 / 降雨 / 抽水站 / AQI / 國道 VD / 飛機）壓成一個 0-100 分。

### 3.1 設計軸 5 件事

| 軸 | 設定 | 設計要點 |
|---|---|---|
| **顯示形態** | A. 環形儀錶 gauge | 主環 0-100 + 中央大數字 + 下方狀態文字；尺寸 120-140px |
| **語意系統** | C. 戰情等級 | 4 檔：平時 / 留意 / 警戒 / 緊急 |
| **平滑** | B. 5min EMA | 數字不每秒跳；過渡動畫 600ms |
| **比較基準** | A+B 雙比較 | 顯示「↗+9 vs 平常週日同時段 / ↗+5 vs 1h 前」兩行 |
| **展開細節** | B. 長條圖 | 點環 → 滑出抽屜，10 條長條告訴你「哪個 signal 拉高」 |

### 3.2 4 檔顏色 + 閾值

| 分數 | 等級 | 顏色 | 動畫 |
|---|---|---|---|
| 0–35 | **平時** | 淡綠 / 灰 | 靜態 |
| 36–55 | **留意** | 黃 | 環呼吸 4s 週期 |
| 56–75 | **警戒** | 橘 | 環呼吸 2s 週期 |
| 76–100 | **緊急** | 紅 | 脈動 1s + 邊緣發光 |

### 3.3 位置與尺寸

- **位置**：IntelHeader 最上方左側（取代現在的「29 事件」KPI）
- **尺寸**：120-140px 環，右側保留事件數與來源健康
- **展開抽屜**：點環 → 從 IntelHeader 下方滑出 200px 高的 10 軌條形圖

### 3.4 預設權重「災害重」

10 個 signal 加權：

| Signal | 權重 |
|---|---|
| 電網 | 0.05 |
| 路況 | 0.05 |
| 急診 | 0.10 |
| **地震** | **0.20** |
| **災害示警** | **0.20** |
| **降雨** | **0.20** |
| 抽水站 | 0.10 |
| AQI | 0.05 |
| 國道 VD | 0.03 |
| 飛機 | 0.02 |

**事件衰減**：地震 + Extreme 警報觸發後 **60min 半衰期**（讓警示帶持續 2-3 小時又能正常化）

### 3.5 平時範例（給設計師調色用）

| 情境 | 分數 | 狀態 |
|---|---|---|
| 週日下午 3 點台北無事 | 28 | 平時（淡綠） |
| 小雨 + AQI 100 | 42 | 留意（黃） |
| 颱風來襲 + 多縣降雨警報 | 68 | 警戒（橘） |
| 地震 M6 + 多縣 Extreme 警報 | 92 | 緊急（紅 + 脈動） |
