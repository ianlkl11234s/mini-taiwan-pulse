熱區與網格的配色選擇

範圍：只有熱區與網格圖層可以換色，色盤只放「序列色階」（由低到高）。每題先看「現況」截圖（3752 原型），再看 A／B／C／D 選項：左邊是台灣面板（消防栓），右邊是日本面板（宗教設施），用站內真實 token 重建、底下是程式產生的示意熱區，不是真資料。右上角可切暗色／淡色。點每題下方的字母選答案，頁尾會整理成一段文字，可一鍵複製貼回對話。完整稽核見 design-audit.md。

盤點

先看現況：三件事

1. 台灣和日本面板其實是同一套

  • 量過字級、顏色、間距，完全一樣（同一個元件、同一份 CSS）。
  • 看起來不同是因為內容：日本主題列沒有英文副標、沒有「安全與治理」這類大分類、圖層名是中＋日文常換兩行。
  • 最明顯的是「顏色」那一列位置不固定：台灣在第 2 列、日本在第 1 列；而且原型裡日本那層顯示三個色塊、台灣顯示色條。

2. 原型對照設計規格：5 項不通過

  • 自動檢查 15/15 通過；人工檢查發現：選中標記用文字「✓」、中文套到英文小字的字型、清單項目沒有焦點外框、提示卡按鈕不是標準按鈕、提示卡焦點色用橘不用藍。
  • 清單往下展開會被面板底緣裁掉，13 組只看得到 3 組（下圖）。
  • 色盤按鈕是自製的「類選單」，規格只有原生選單，要新增一條元件規格。

3. 現在的熱區色本身就要修

  • 全站熱區共用 magma。驗證器：暗底最淡端對比 1.33:1、淡底最密處 1.04:1，兩種底圖都不及格。
  • 淡色底圖上最密的地方是淡黃，幾乎看不見（下圖右）。
  • 範圍：熱區 45 層（台 36、日 8、全球 1），網格 28 個（台 15、日 13）；雨量、溫度、噪音、買賣（發散色）等 5 種語意色不開放換色。
