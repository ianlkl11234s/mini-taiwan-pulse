# 科學色階總覽：驗證結果

> 2026-10-03。選擇頁：[`ramp-gallery.html`](./ramp-gallery.html)。起因：[`PROPOSAL.md`](./PROPOSAL.md) §0 Q3「要更多科學色階，特別是多色相」。方法沿用 [`design-audit.md`](./design-audit.md) §4。
> 產生、驗證、相似度腳本放在 session scratchpad，不進 repo（同 design-audit）；色值以本檔與頁面內嵌資料為準。

## 0. 白話摘要

1. 候選 **56 組**（matplotlib 5、seaborn 4、ColorBrewer 12、CARTO 12、Crameri 14、cmocean 9），**40 組通過**，2 組驗證器不通過，14 組因亮度跨度不足排除。
2. 排除的多半是**最深處不夠深**的色階（CARTO 的 Sunset、BluYl、Teal、Mint、Purp，Crameri 的 imola、hawaii、nuuk）：在淡色底圖上要「越密越深」，它們排不出 7 個看得出差別的深淺。暗底版都還可用，若之後放寬成「只在暗底提供」可再撈回。
3. 因為所有色階都對齊同一組亮度，兩組好不好分只看色相與彩度。用「暗或淡任一版平均 ΔE < 8 算太像」，**彼此都分得開的最多只有 12 組**（已窮舉確認），所以建議清單是 12 組，再多一定有兩組太像。
4. 建議收錄 12 組：翠綠 viridis、岩漿 magma、黃橙褐 YlOrBr、黃綠藍 YlGnBu、藍紫 BuPu、紫藍綠 PuBuGn、酒紅 Burg、巴特洛 batlow、阿克頓 acton、東京 tokyo、畢爾包 bilbao、流速 speed。其中 11 組是多色相（只有 Burg 是單一色相）。現行 magma 保留為預設；cividis（現行公司年齡網格在用）和 batlow 淡底太像（ΔE 6.3）、和 tokyo 也太像，建議收 batlow，cividis 列備選。
5. 本頁 magma 與 design-audit 驗過的 magma 幾乎相同（平均 ΔE 暗 0.5、淡 0.8），差在本次直接取樣 1024 點色表，design-audit 用錨點內插。

## 1. 方法

| 項目 | 設定 |
|---|---|
| 色表來源 | 本機 venv：matplotlib 3.11.2、seaborn 0.13.2、cmocean v3.0.3、cmcrameri 1.8、palettable 3.3.3（CARTO Colors） |
| 取樣 | 連續色表取 1024 點；CARTO 只有離散色，取官方 7 色錨點在 OKLab 線性內插。每點算 OKLab L，取 L 單調包絡後反查色表位置 t，在 t 上的 OKLab 內插取色（不改色相、不手調） |
| 7 階位置 | OKLab L 等距。暗版 0.47→0.95（低密度→高密度，越密越亮），淡版 0.72→0.30（越密越深）；兩端再夾到色表本身的 L 範圍。不管來源方向，一律依亮度排序（例如 YlOrRd 暗版是「紅→黃」） |
| 截取 | 近底圖那端預設 0.47／0.72；驗證不過時先往內收（每次 0.005，暗至 0.50、淡至 0.69），仍排不出再往外放（暗至 0.45、淡至 0.755），都由驗證器判定。實際用到的偏移：plasma 暗 0.48、RdPu 暗 0.475、YlOrBr 淡 0.725、Burg 淡 0.73、OrRd 淡 0.74、YlOrRd 淡 0.75；其餘都是預設值 |
| 排除門檻 | 截取後亮度跨度 < 0.36（6 個間隔 × 0.06）→ 排不出 7 階，不送驗證器 |
| 驗證器 | dataviz `validate_palette.js --ordinal --mode dark|light --surface …`（亮度單調、相鄰 ΔL ≥ 0.06、近底圖那端對比 ≥ 2:1、單一色相 ≤ 40°） |
| 底圖陸地色 | 暗 `#262626`、`#1f1f1f`；淡 `#f5f5f3`、`#ffffff`（同 palette-validation.md） |
| 單一色相 | 多色相色階標 **N/A**，只在其他三項都過時才算通過。另注意：驗證器的色相跨度不是環狀計算，跨過 0° 的紅紫→黃色階（magma、inferno、plasma、rocket、matter、thermal、PuRd）會被誤判成「單一色相通過」；表中「單一色相」欄改用環狀跨度（只計彩度 ≥ 0.03 的階），跨度 > 40° 或驗證器不過都標 N/A |
| 相似度 | 同一階兩組顏色的 OKLab ΔE×100，7 階平均，暗、淡各算一次；**任一版 < 8 = 太像** |
| 預覽 | 頁面上的熱區／網格都是固定亂數產生的假資料，所有色階共用同一份；熱區照 Mapbox heatmap 的形式（0 透明 → 第 1 階 → … → 第 7 階） |

## 2. 建議收錄（12 組，預設勾選）

## 6. 對提案的影響

- PROPOSAL §4 色盤庫「科學色階」區：由 design-audit 的科學 8 組（含 Blues 等單色）擴成使用者在本頁勾選的清單；預設勾選的 12 組可直接當 v1。
- 「越密越亮／越深」的反轉規則對多色相色階同樣成立：淡版的色相順序與暗版相反（例：YlGnBu 暗底是藍→黃、淡底是青藍→深藍，黃色端被截掉），圖例要照當下底圖畫。
- 多層熱區同時開時，色盤庫本身最多只能保證 12 組彼此 ≥ 8，仍低於 dataviz 正常視覺下限 15；Q6 的降透明度規則仍需要。
