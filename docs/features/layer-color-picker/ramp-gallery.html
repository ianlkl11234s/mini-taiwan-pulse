科學色階總覽

熱區／網格色階：要收哪些？

每組都從來源套件的正式色表取樣 7 階，做暗、淡兩版：暗底越密越亮、淡底越密越深，密度 0 透明。兩版都用 dataviz 驗證器對兩種陸地色檢查（暗 #262626／#1f1f1f、淡 #f5f5f3／#ffffff）。

「太像」＝同一密度兩組顏色的平均差異（OKLab ΔE×100）在暗或淡任一版小於 8。因為所有色階都對齊同一組亮度，差異只剩色相與彩度。預設勾選的 12 組是建議清單：彼此在兩版都至少差 8，在這個門檻下最多只能同時收 12 組，要換其他組得拿掉跟它太像的那組。

預覽是程式產生的假資料（同一份熱區密度與網格數值套不同色階），不是真實圖層。
