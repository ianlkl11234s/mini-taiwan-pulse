## 結論

- 提案 `hide-zero`：`companyCapitalGrid`、`companyPoints`、`companyIndustryDistribution`。前兩者的 source 是 occupied-only/non-empty；產業分布已把「選定產業總和=0」畫成透明，缺欄位仍為 slate neutral。三者皆不需要再加 filter。
- 提案 `keep`：其餘 11 層。原因不是視覺偏好，而是 0 為有效量測值、模式依賴、來源只代表可定位 records，或本機沒有 tile payload 能確認安全零值條件。
- 提案 `hatch`：0。這批 registry grid 沒有可證實的 missing/suppressed 欄位且目前又被畫成與零相同的情況；擅自加 hatch 會捏造 coverage 狀態。
