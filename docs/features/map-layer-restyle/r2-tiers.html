R2 點圖層：每層預設用哪一階

P-1 B 拍板後，點的大小不隨縮放，固定三階。下表列出全部 314 個點圖層：192 個讀得到確切數值（runtime），122 個是圖層自己的程式畫的（標 hook，數值可能混到同一支程式裡其他圖層的值，改的時候會在瀏覽器實看）。

「現在」欄是 z14 的實際半徑（依資料放大的畫最小與最大），「改後」欄是建議的階，都是 1:1 像素、用圖層識別色畫在地圖底色上。建議規則：現在 ≤3px → 小；≥9px → 大；依資料放大 → 泡泡（面積對應數值，4–28px）；其他 → 中。不同意的直接點按鈕改，頁尾會列出你改過的層。
