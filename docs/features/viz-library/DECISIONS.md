## 驗證方法

所有色碼都以 dataviz `validate_palette.js`（Machado 2009 色盲模擬、OKLab ΔE×100）驗過，
底圖面：暗 `#1b1f27`、淡 `#e7eaee`。類別色跑 categorical 檢查；色階跑 `--ordinal`（單調、相鄰 ΔL ≥ 0.06、淺端對底圖 ≥ 2:1）。
現成的 Okabe-Ito、Paul Tol 在兩種底圖上都沒通過，所以類別色是 Pulse 自調。

## 1. 配色

### 1.1 整體方向（C1 = B 科學均勻）＋分工規則

| 用途 | 色階 |
|---|---|
| 資料的多寡（區域深淺、泡泡顏色、格點、立體柱、流向） | **viridis（截）** |
| 熱力 | **magma（截）** |
| Agent 畫的分析範圍（等時圈、直線距離圈、選取） | **品牌藍** |
| 結果疊在其他彩色圖層上時 | 藍或琥珀單色（備用） |
| 正負比較 | 藍–灰–琥珀（C4 = D1） |

**同一色階暗／淡底圖方向相反**：暗底圖越亮越多；淡底圖越深越多。註冊表只寫色階名稱，渲染時依底圖取對應 5 格。
預設 5 級；等時圈 3 級。

### 1.4 缺值（C6 = N1）
透明底＋45° 細斜線（暗：白 35%；淡：黑 35%）。缺值不得畫成 0 或最低級。現況 `#bdbdbd` 淘汰。

### 1.5 兩個指標（C5 = V3）
不用 3×3 bivariate。一個指標用區域深淺（viridis），另一個用泡泡大小；泡泡只畫前 N 名。

## 3. 細節（第 3 輪）

| 題 | 定案 | 規格 |
|---|---|---|
| L1 線 | W1 | 線寬 細 1.5／中 2.5／粗 4 px；外加 1.5px 底色外框；分類用類別色、數量用 viridis |
| L2 流向 | F3 | 弧線（粗細 ∝ √量、viridis、終點小點）＋ 1.8px、50% 透明的小點慢速流動；**≥ 30 條或減少動態 → 退回 F1 純弧線** |
| N1 數字 | U1 | 人數／件數 ≥ 1 萬寫「1.2 萬」（1 位小數，去尾 .0）；< 1 萬千分位；密度、比率一律千分位；百分比 1 位小數；有單位必寫；缺值寫「無資料」 |
| N2 標籤 | A1 | 只標名稱，前 N（預設 5）；CJK 10px 粗體＋3px 底色描邊；重疊時排名低的讓位。分析卡匯出時可選加數值（待分析卡項目確認） |
| G1 圖例位置 | D1 | 併入現有「圖例」面板，分析結果排最上；popup 開啟時圖例移到 popup 上方並收成精簡版（標題＋色階） |
| G2 圖例內容 | ✔ | 四行：標題＝指標＋單位 → 色階＋實際分界數字 → 方法與缺值 → 來源一行；精簡版只留前兩行 |
| I1 滑過 | H1 | 2px 主色描邊＋游標旁一行「名稱＋主要數值」 |
| I2 選取 | X1 | 選中者原色＋主色描邊，其他降到 35%；popup 關閉即恢復 |
| S1 疊加 | O1 | 最多 3 個結果；區域深淺／格點同時只一個填色，其餘自動只畫邊線；熱力同時只一個。上下順序：選取圈 → 標籤 → 點 → 線與流向 → 泡泡 → 等時圈 → 區域／格點 → 熱力 → 底圖 |

## 4. popup 欄位（S 表，外框依 UI B 版）

eyebrow「分析結果 · 圖層名」，最下接 F2 來源列。

| 樣式 | 欄位（依序） |
|---|---|
| choropleth | 區名 → 數值＋單位 → 第幾級／5 → 來源・時間 |
| proportional | 名稱 → 大小指標＋單位 → 顏色指標＋單位 → 排名 → 來源 |
| heatmap | 無 popup；圖例寫單位 |
| compare | 區名 → A、B 兩值 → 差或比（含正負號）→ 來源 |
| bivariate（V3） | 區名 → 兩個指標各自的值 → 來源 |
| isochrone | 「步行 15 分鐘範圍」→ 面積 → 範圍內件數 |
| grid | 格內件數 → 占全部 % → 來源 |
| points | 名稱 → 類別 → 2～3 個重點欄位 → 來源 |

## 5. 與 UI 統一的接縫

- popup 固定右下角（B 版細線緊湊）、F2 來源列、H2 標頭、C2 按鈕、V2＋S1 控制項、T2 工具列、「圖例」中文、系統字（中文 `--font-cjk`、數字 `--font-data`）。
- **選取圈**（UI R2）：主色藍、往外擴散、1.8s；**即時脈衝**（M8 R2）：資料色、原地呼吸、2.4s。形狀、顏色、節奏都不同。
- 數值（地圖標籤、圖例刻度、popup）用 `--font-data` tabular-nums；名稱、單位、說明用 `--font-cjk`。
