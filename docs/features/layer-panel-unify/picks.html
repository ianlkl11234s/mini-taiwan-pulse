圖層面板統一

所有圖層面板統一成同一套：逐題決定

範圍：台灣、日本、統計、世界四個圖層面板，加上手機的圖層與統計分頁，以及另外各自寫的清單（資料來源、Agent 分析結果、衛星群組、我的）。先看「現況」，再逐題選。每個選項都用同一套元件同時套在台灣（寺廟）、日本（宗教設施）、統計（失業率）、世界（全球地震）四種真實內容上並排，讓你直接看到統一後的樣子；面板是用站內 token 重建的示意，不是截圖。右上可切暗色／淡色。點每題下方的字母選答案，頁尾會整理成一段文字，可一鍵複製貼回對話。完整盤點與程式位置見同目錄 AUDIT.md。

現況

四個面板其實是同一個元件，但看起來不像

1. 桌機四個面板＝同一個元件

  • 台灣、日本、統計、世界都是 LayersPanel，只差餵進去的內容與幾個開關（有沒有大分類、有沒有「單一／可重疊」）。
  • 所以「看起來不一樣」幾乎都來自資料：名稱怎麼寫、主題有沒有英文、設定項目順序。
  • 統計的設定區另外插了一塊手寫的「資料篩選／位置口徑／來源」，透明度被擠到最後。

2. 手機是另一套

  • 只有「圖層／統計」兩個分頁，日本與世界混在圖層分頁裡（下圖：長照服務、全球通訊夾在台灣主題中間）。
  • 圖層分頁用空心圓點當開關；統計分頁卻用正常開關。
  • 名稱用另一個欄位 labelMobile，把筆數寫死在名稱裡（「寺廟 (19,201)」），英文也不見了。

3. 另外四份各自寫的清單

  • 資料來源：自己的列與拆名字函式（跟主題列那支規則不同）。
  • Agent 分析結果：原生 checkbox；衛星群組：開關在 chevron 前、用藍色；我的・已開啟：名稱下兩顆按鈕。
  • 搜尋各面板各自、只搜本面板；圖例入口不在側欄。

實作切分（選完之後的階段計畫）
