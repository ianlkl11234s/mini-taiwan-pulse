大分類：統計・世界

統計與世界面板的大分類怎麼分

P4 已選 A（每個面板都有大分類）。台灣已有，日本已定（行政與人口、交通與旅宿、醫療與照護、社會、自然與環境）。這頁只決定統計和世界。命名規則：統計與世界的主題本來就有英文副標，大分類的資料照台灣寫成「中文 English」，面板上只顯示中文（跟台灣一樣）；日本用純中文，是因為日本主題本來就沒有英文。每個選項附「大分類 → 主題」表，旁邊是套用後的面板示意（站內 token 重建，不是截圖；主題預設收合，第一個主題展開看裡面的小分組）。點每題下方字母選答案，頁尾可一鍵複製。
