# 統計整合修訂：2026-09-16 使用者決定

本文件取代前版「教育合併4入口、住宅全部合併1入口、交通大幅合併」建議。其餘已接受項目保留。本次為設計與來源查證，尚未改動正式介面。

## 教育：學制固定，老師與學生分開

現有來源學制確定為幼兒園、國小、國中、高中，共4種；沒有在本包中提供大學，不自行補出。

建議4個學制分組，每組直接列出3個可獨立開關入口，共12個入口：

| 學制 | 學校端 | 老師端 | 學生端 |
|---|---|---|---|
| 幼兒園 | 幼兒園機構 | 幼兒園老師與職員 | 幼兒園幼生 |
| 國小 | 國小學校 | 國小老師與職員 | 國小學生 |
| 國中 | 國中學校 | 國中老師與職員 | 國中學生 |
| 高中 | 高中學校 | 高中老師與職員 | 高中學生 |

每個入口固定education_stage，不再進去切學制。學年可切，且保留同學制先前選擇。

- 學校端：機構／學校數；國小另外保留12班以下學校數與占比。
- 老師端：教師數、職員數；國小／國中／高中可選既有生師比（學生／教師）。不得把職員加進教師分母。
- 學生端：學生／幼生數、年增減數／率；國小／國中／高中另外有班級數及每班學生數。
- 現有幼兒園沒有發布班級數、生師比、每班人數；小校兩項僅國小。資料可用矩陣來自socialStatisticsRecipes.json的exact dimensions，其他學制不顯示不存在的選項。

### 教育比較的優先度

1. 優先既有生師比、每班學生數、學生年增減率：直接回答教學負荷与規模變化。
2. 人口：學校或教師數／對應學制適齡人口×10000；學生數／適齡人口只標「學校所在地學生相對適齡人口」，不可稱入學率，因跨區就學。
3. 面積：學校數／官方行政陸地面積×100，單位校／100km²，回答設施集中程度；教師／學生面積密度可作選配，但不是教育品質或服務可達性。
4. 幼兒園legacy_104_110與current_111_114不可跨source_schema作增減；學年度与人口快照的配對需明訂，不直接以曆年名稱相同推定一致。

實作注意：現有統計以indicator layer key儲存狀態；新的學制入口是同key不同固定dimensions。若需多學制同時比較，必須有獨立view識別及選擇狀態，不能讓選高中覆寫國中。原始URL/key仍應相容，不複製上游數值。

## 住宅：使用類別為入口，地理層級在內切換

共7個主入口：

1. 住宅總數：縣市／鄉鎮；原始總数，可評估每戶住宅（需同年戶數）。
2. 有人經常居住住宅：縣市／鄉鎮，總數／占全住宅比例（已有）。
3. 無人經常居住住宅：縣市／鄉鎮，總數／占全住宅比例（新候選）。
4. 偶爾自住住宅：縣市／鄉鎮，總數／占全住宅比例（新候選）。
5. 自住以外用途住宅：縣市／鄉鎮，總數／占全住宅比例（新候選）。
6. 目前沒有使用住宅：縣市／鄉鎮，總數／占全住宅比例（已有）。
7. 住宅用途占比（僅縣市）：住宅專用／兼農工服務業用。新增候選各類數量÷同縣市住宅總數×100%；原始數量在popup保留。這個分母是全部住宅，不標成「有人居住住宅內部組成」，兩項也不假定加總100%。若未來改採內部組成，須先核對官方分類樹及父類分母。

所有資料維持2020-11-08普查標準日、STALE、原始類別定義；缺值不補0，地理切換不把縣市值分攤到鄉鎮。

## 交通：建置量／使用狀態分組，保留細項入口

使用者不接受前版大幅合併；兩種視角是分組標題，並非把全部指標收成兩個layer。

- 建置量：公車車隊、路線、業者；市區自行車站、河濱站與車輛；路外／路邊停車；道路／鐵路／機場／港口用地。保留細項快速入口。
- 使用／營運狀態：公車班次與車公里、市區／河濱租借、捷運出站、機場旅客／貨運／起降，仍分系統與資料範圍。
- 車輛登記、駕照是登記存量／持照背景，不改稱實際使用狀態。
- A1/A2事故與傷亡作「交通安全」獨立分組，銜接曝險與登記車輛比較。
- 人口標準化：公共運輸供給／同年人口，站點或停車供給／人口；機場及系統旅客所在地人次不解讀為居民搭乘率。
- 面積標準化：建置數／官方行政面積。使用量／面積仅為行政區活動密度，不是使用效率；效率優先採每站租借或相容車輛／營運量。

### 交通安全的新需求

- 查證全國A2及A3是否有同年、同地理層級的公開統計；來源查證與下載結果見traffic-source-check.md。
- 傷亡事故總量優先A1+A2；A3屬財損事故，只有同口徑完備來源才加入全部事故，不以缺A3當0。
- 每十萬人口事故／傷亡數：事故或人數÷同年人口×100000。
- 每萬登記車輛事故數：事故件數÷同年同地理範圍登記車輛×10000；標記「相對登記規模」，非行車風險，不能聲稱分子車輛都是當地登記。
- 每億車公里事故／死亡數：事故或死亡數÷同期間同道路範圍同車種車公里×100000000。公車營運車公里不能作全部道路事故分母；全國車公里不能分攤成各縣市曝光量。
- 24小時A1死亡與30日死亡分開，不以同名「死亡」串接歷年。

## 農林漁牧：總量、當地結構、全台貢獻三視角

### 共通公式

1. 原始總量：X_i。
2. 當地土地占比：用地公頃_i ÷（同區官方土地km²×100）×100%。
3. 全台同類占比：X_i ÷ X_全台×100%。分母是同年同類同母體的全台總量；缺值、抑制及部分地區未報須先檢核，不偷偷加總已觀測值冒充全台。
4. 在縣市內的鄉鎮貢獻：X_鄉鎮 ÷ X_所屬縣市×100%；與全台占比分開標題。
5. 區位商（進階）：（當地該類用地／當地土地）÷（全台該類用地／全台土地）。大於1代表相對全台較集中，不是品質較好。

### 各領域套用

- 農業：水田／旱田／果園等用地的當地土地占比、占全台同類用地比例；作物收量用全台同作物同一期作占比。複種收穫面積不標土地覆蓋率。
- 畜牧：同畜種在養數占全台同畜種在養數、場數占比、每場頭數；在養數／官方行政面積是頭數密度，不是土地占比。不可混合豬牛雞為可比「頭數」。
- 漁業：同漁法／物種產量及產值的全台占比；養殖用地可做當地土地占比。海洋捕撈所在地統計不使用縣市陸地面積當生產效率分母。
- 林業：各林型占當地土地、占當地完整林地（若分母可得）、占全台同林型，三者清楚命名。

例（純示意，非台灣實測）：甲縣土地100000公頃、水田20000公頃，全台水田200000公頃。當地水田占20%，全台水田貢獻10%；兩者回答不同問題。

縣市彙總必須由同boundary、同period、同分類的鄉鎮值依正式行政碼對照加總；若有缺鄉鎮則仍PARTIAL。全台口徑（22縣市及離島、是否另列其他地區）必須與分子一致。
