面板互斥示範 ＋ 時間軸精簡版

上半部：A1／A2 的互動示範，按「下一步」看 Agent 打開地震回放時畫面怎麼變。下半部：時間軸保留刻度形式、縮小占用空間的 4 個版本，每版以接近實際大小的完整畫面呈現（暗色），下方附淡色小圖；右上角標出占畫面比例。

回覆格式：「A2、時間軸 TC3」。

A

Agent 打開地震回放時

選一
步驟 1／3：Agent 面板開著，正在分析
A1照規則收起 Agent
A2例外：Agent 不收
  • A1：地震回放取代 Agent 面板的位置；Agent 仍在連線（rail 上的 Agent 圖示有綠點），點圖示就回來。畫面乾淨，但分析進行中看不到它的即時紀錄。
  • A2：地震回放開在 Agent 面板上面（後開的在上），Agent 面板被壓在下面、露出一點邊；要看 Agent 時把地震回放關掉或點 Agent 圖示切回。
T

時間軸：保留刻度，減少壓迫

選一
  • 現況（TL3）：兩列卡片，約 620×100px，占畫面約 6.8%，加上大號 20px 時間與整排控制，視覺重量集中在左下。
  • 四版都保留：刻度、目前時間指針、資料缺漏斜線、拖曳跳轉；日期與範圍改收進小膠囊（點開才出現完整選擇）。
  • TC1 單列精簡：播放、時間、倍速、刻度軸、日期膠囊排成一列卡片，高度減半。
  • TC2 貼底細條：整條貼齊畫面底部、左到右全寬，只有 28px 高、上緣淡出，沒有卡片框；控制縮成兩端小字。像影片進度條，最不擋地圖。
  • TC3 收合＋展開：平常只是一顆小膠囊（播放、時間、細進度線）；滑鼠移上去或點一下才展開成完整刻度軸。平常最小，操作時才完整。
  • TC4 無底框浮字：保留兩列資訊但拿掉卡片底色，文字與刻度直接浮在地圖上（加淡陰影），字級縮小；資訊量不變、重量最輕，但在亮色／複雜底圖上可讀性較差。
