現況找到的問題

1. 一閃即逝有任務就立刻出現，全部結束就立刻消失，沒有「完成」狀態，也沒有最短停留時間。載入只要 0.1 秒時，看起來就像畫面閃了一下。src/components/LoadingIndicator.tsx:21
2. 格式不在 design system 裡英文大寫「LOADING」、「+N more」；字型寫死 -apple-system（不是 FONT_CJK）；淡色版用手寫 hex；每個任務前面加「•」。LoadingIndicator.tsx:47,84,93
3. 和 Agent 活動卡撞在一起載入提示在 top 110px，Agent 活動卡在 top 100px，兩個都靠右，同時出現時會疊在一起；載入提示的 z-index 1000 會蓋過活動卡。LoadingIndicator.tsx:40 · researchActivity.css:4
4. Agent 白色光暈直接出現、直接消失Agent 忙碌時整個畫面加一層白藍色內陰影光暈，用 React 條件渲染直接掛上、拿掉，沒有淡入淡出；動畫一開始就從 64% 亮度起跳。淡色底圖上看起來是一圈白邊。步驟之間如果短暫不是「忙碌」，光暈就會熄滅再亮起，看起來像閃一下（這點要實作時再確認）。ResearchActivityCard.tsx:8 · researchActivity.css:5

2. 顯示節奏

S1、S2 共用同一套規則；上面的播放就是照這套規則跑
規則數值為什麼
出現前延遲150ms150ms 內就完成的背景載入（例如時間軸換一格）不跳提示，避免閃爍
「載入中」最短停留600ms一出現就要讓人讀得到，不會一閃就變成「完成」
合併等待300ms全部結束後再等 300ms，這段時間有新任務就繼續算同一批，不會反覆出現、消失
「完成」停留1.2 秒，再淡出 300ms你要求至少顯示「完成」並停 1～2 秒；出現到消失總長至少約 2.2 秒
失敗停留 4 秒，錯誤色失敗需要被看到；要改 withLoading 記錄失敗（現在只有開始、結束，沒有失敗狀態）
進行中換任務文字淡出淡入 160ms只換字，不重跑整個出現動畫，框也不會跳動
時間軸播放播放中只顯示「載入中」，停下後才顯示「完成」連續重載時不會一直跳「完成」
減少動態偏好不位移、不轉圈，只換文字符合 prefers-reduced-motion
