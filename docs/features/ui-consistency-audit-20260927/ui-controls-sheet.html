圖層調整控制項

選版面＋滑桿
  • 盤點：約 770 個圖層規格；控制項 4 種：滑桿（約 1,092 個）、選單（106；3 個選項以內顯示成分段按鈕）、開關（64）、多選清單（21）。另有醫療統計、統計詳情等 4 個手寫控制元件。
  • 現況問題：標籤和數值黏成一串（「Opacity 0.85」「Shuttle Z +0m」）、中英混用（Opacity／透明度並存）、等寬字、滑桿頭是瀏覽器預設、開關是「ON／OFF」文字、展開箭頭有 ▶ 和圖示兩套、「Hide」是英文字按鈕。
  • 共通改法：標籤一律中文（透明度、大小、高度、光點、尾跡、配色）；數值獨立靠右對齊、等寬；開關改迷你切換；「Hide」改成眼睛圖示；展開箭頭統一一種；控制區左側用左線（與 Layers 群組、時間軸同一語彙）。
