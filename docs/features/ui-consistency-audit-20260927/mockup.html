7. 額外範例 — 泡泡圖

示範建議 token 落地在資料圖表上的樣子：圓面積＝學校數（identity/magnitude），顏色＝補習班密度（單一色相由淺至深，magnitude）。 下列數值為示意資料，非真實統計，僅用於展示視覺規格（薄描邊、方向性色階、前 5 名直接標籤、圖例常駐）。

補習班密度（示意，越深越高）
學校數（圓面積，與上方泡泡同比例尺 r=10×√n）
規格依循 dataviz skill：半徑 = k×√學校數（同一 k 值用於主圖與圖例，故面積、非半徑，與學校數成正比）、 單一色相序列色階（非彩虹）、圓形薄描邊避免與背景融合、僅前 5 名直接標籤（不逐點標數字）、 size／color 各自常駐圖例、文字一律用 --text-* 中性色（不吃資料色）。實際上線時序列色階需另跑 validate_palette.js 驗證明暗對比與色盲可辨性，本頁僅為視覺規格示範，5 站數值皆為示意。
