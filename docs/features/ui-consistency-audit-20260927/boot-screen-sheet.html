開站畫面：三個方向

目前開站畫面只在等地圖畫完一件事（其他圖層預設都關），卻放了進度條（0/1 → 100% 一下跳完）、一個永遠只顯示「Connecting to Supabase…」的空終端框，副標也還是舊的「Supabase Realtime」。字體、漸層進度條、光暈都不在 design system 裡。下面每列左暗右淡，淡色版用在帶 style=light 的分享連結。

目前

B1原地整理

保留全螢幕遮罩，只換內容：標題用左上 HUD 同一套字（FONT_DATA 700）、副標改中文、狀態改成右上載入狀態條同款（§5.30 的轉圈＋文字＋秒數）。

拿掉進度條、終端框、漸層與光暈。完成後顯示「✓ 完成」再淡出（沿用 §5.30 時間規則）。

改動最小，但「等待」的感覺還在。

B2標題落位

遮罩改半透明，底下地圖一邊畫一邊透出來。完成時中央標題縮小、移到左上 HUD 的位置變成正式標題，其他東西淡出，開站到主畫面是同一個畫面接續。

唯一的動畫（約 0.6 秒），減少動態偏好時改成直接淡出。

比 B1 多一段位置計算，體感仍要等地圖。

B3直接進站 建議

不再有全螢幕遮罩。側欄、工具列、時間軸一開始就在，地圖區先是 SURFACE.app 底色；右上載入狀態條（S1）顯示「載入地圖 → ✓ 完成」，跟之後開圖層時看到的是同一個元件。

實作時要驗證：地圖還沒畫完就點圖層，圖層會不會等地圖好了再出現。

最快也最一致：省掉現在固定的 0.6 秒收尾，也不用等「全部資料源空閒」才放行（見下方速度分析）。代價是開頭約 1 秒會看到空的暗底。
