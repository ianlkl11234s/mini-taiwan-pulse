左下時間軸：三個版本

沿用已定的規則：中文 --font-cjk、時間與數字 --font-data、按鈕 C2、分段控制、S1 細滑桿、左線／細線分隔。每版都畫「即時模式」與「歷史模式」，暗、淡色並排。

回覆格式：「時間軸 TL2、眼睛 E3」。

「眼睛」是什麼

選一
↖ 開關正下方、右側那個劃線的眼睛，就是原本英文「Hide」按鈕改成的圖示。

它的作用是「關掉這個圖層並收合控制區」，跟右上角的開關幾乎一樣，卻自己多占了一整列（約 20px）。
  • E1 維持：留在控制區右上角的獨立一列。
  • E2 移到圖層列：放在展開箭頭旁，不再多占一列；但圖層列上會同時有眼睛和開關兩個「關掉」的方式。
  • E3 拿掉（建議）：開關本身就能關掉圖層；收合則按展開箭頭。少一個重複的按鈕，控制區直接從第一個控制項開始。

時間軸

選一
  • 現況：日期列（◀ 9/27（日）▶、Now、1d 下拉）＋播放列（▶、60x 下拉、時間）＋一條原生滑桿與兩端時間，全部等寬字、灰底按鈕、英文 Now／1d／60x。
  • 三版共通：「Now」→「現在」、「1d」→「1 天」、「60x」→「60×」；播放鍵改圓形主要按鈕；滑桿改 S1；資料時段外的提示（例如漁船資料只到某日）改成警示色小標籤。

  • TL1 精修卡片：保留現在的三列結構（日期／播放／進度），放進與其他面板相同的卡片裡。改動最小、最好上手。
  • TL2 單列膠囊：播放、時間、進度條、倍速排成一條；日期收進右側日期膠囊，點開才出現日期切換、範圍與「現在」。最省空間，地圖露出最多。
  • TL3 刻度時間軸：底部較寬的時間軸，有整點刻度、目前時間指針，資料缺漏時段用斜線標出。最有情報儀表的感覺，但比較寬。
