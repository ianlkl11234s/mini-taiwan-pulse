速度 每段都會自動循環；載入時間固定示意 1.6 秒

開站動畫：五種進場

共同規則：載入中只有底色＋狀態（S1 同款），地圖畫好後狀態變「✓ 完成」停 0.4 秒，接著各元件用不同方式歸位。每種左暗右淡。動畫只在開站跑一次；系統設定「減少動態」時一律改成直接淡入。

M1液態歸位 收尾約 1.2s

載入時中央是一顆會呼吸的金屬液滴。完成後液滴分裂成幾顆小水滴，各自拉長、流到側欄／工具列／時間軸／標題的位置，落定後變成真正的元件。

分裂時水滴之間會像水銀一樣互相黏住再斷開（SVG 融合濾鏡）。

最特別、最有記憶點；實作要多一層濾鏡圖層，只在開站用一次，效能影響小。

M2機關展開 收尾約 1.2s

先只有底圖慢慢浮現。完成後側欄從左邊滑入、工具列從上方落下、時間軸從下方彈上、標題最後落定，每個都有一點回彈；側欄圖示依序彈出。

工具列和時間軸卡到定位時邊框閃一下強調色，像機關「喀」一聲卡住。

就是你描述的第二種；實作最單純（只用位移）。

M3掃描顯影 收尾約 1.1s

載入時是經緯格線，一條細線從上往下反覆掃。完成後一道光束由左往右掃過，光束經過的地方地圖和元件一起顯影。

像雷達或衛星影像的逐行成像，呼應「即時監測」的主題。

俐落、不花俏，節奏最快。

M4脈動擴散 收尾約 1.1s

載入時台灣位置有一個跳動的點，一圈圈往外擴（像 Logo 的脈搏）。完成後一道波從那個點擴散出去，波經過的地方整個畫面亮起來，離中心越遠越晚出現。

直接用上 Pulse 這個名字的意象。

中心點可以改成使用者上次看的位置。

M5藍圖描線 收尾約 0.8s

載入時在格線上用虛線描出各元件的輪廓，標題是空心字。完成後輪廓填色、標題填滿、地圖浮現，格線退掉。

像工程藍圖變成實體；等待期間畫面不空，使用者也先知道東西會出現在哪。

適合載入比較久的時候。
