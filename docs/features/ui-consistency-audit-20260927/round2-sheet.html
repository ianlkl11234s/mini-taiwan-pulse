Inter 字型殘留

確認
  • 原本：還有 11 處指定 Inter 字型（多在 Layers 側欄，另有 App、提示訊息、面板標頭、統計詳情各一處）。本機沒裝 Inter，實際會退回系統字，但寫法跟規範不一致。
  • 改成：一律改用中文字型變數（--font-cjk）；自動檢查加一條規則，之後不能再出現 Inter。畫面幾乎不會有變化。
