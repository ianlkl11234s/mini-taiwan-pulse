圖層開關：兩種尺寸

站上有兩種開關。規格 §5.10 只寫了小的那種，大的（Layers 每一列右邊那顆）沒寫進規格，所以元件頁把它標成「不符」。另外，上次說「淡色底圖上看不見」，是元件頁用元件的預設顏色展示造成的；實際的 Layers 面板會依主題傳入顏色，淡色看得見（下圖第一列就是現況）。

大開關（LayerToggleSwitch，28×16、圓點 12）：Layers 每個主題與圖層列、分析結果清單、醫療統計群組。開＝暗色白底黑點／淡色深底白點（黑白，不用強調色）。

小開關（.lpc-sw，20×11、圓點 7）：圖層展開後的細項控制（顯示站名、光柱…）、底圖選單「顯示地名」。開＝強調藍。規格 §5.10 只寫了這種。

規格另寫的「工具列／面板 24×14」目前沒有任何地方在用。

元件內建的預設值是暗色版（開＝白色）。目前所有實際使用的地方都有依主題傳入顏色，所以畫面上不會發生；元件頁當初沒傳顏色才看到右圖。風險是之後新地方直接用、忘了傳顏色，在淡色面板就會白底白軌道。修法很小：讓預設值自己跟著主題。

兩種開關「開」都用同一個強調藍，全站「啟用中」語意一致。尺寸維持兩階（列 28×16、細項 20×11）。改動：一個元件＋三處傳色。

缺點：Layers 清單開很多層時整排藍點，比現在的黑白醒目。

S2維持現況，只補規格 建議

外觀就是上面「現況」那組，不改畫面。規格 §5.10 改寫成兩階：列開關 28×16、開＝黑白（依主題）；細項開關 20×11、開＝強調藍；刪掉沒人用的 24×14。

理由：列開關是「整層開關」，用中性黑白比較穩，細項用藍色標出「這層裡哪些選項有開」，兩者層級本來就不同。

一併讓元件預設顏色跟著主題，避免之後踩到。
