Popup 資訊密度：五個候選版

三種 popup（寺廟、文化設施、Agent 分析結果）都套同一個停靠面板骨架（280px、右下角、沒有尖角，依 Q1 的決定）。字型用 Q3 決定的系統字：中文走 --font-cjk，只有數值走 --font-data。每一版只有「列高」和「分隔方式」不同，其餘結構都一樣。

挑一版告訴我代號（A–E），也可以混搭，例如「B 的線 + D 的標籤欄」。
