## Evidence boundaries

Discoverable means a key exists in `LAYER_MANIFEST`; readable means a registered descriptor declares query access. A single GeoJSON path is only a metadata candidate until source readback verifies bytes, schema and geometry. An adapter may serve multiple layers, and a layer may map to multiple datasets. Analyzable is based only on declared descriptor operations and geometry eligibility; rendered points, lines, polygons, PMTiles, or source counts do not establish runtime support.
