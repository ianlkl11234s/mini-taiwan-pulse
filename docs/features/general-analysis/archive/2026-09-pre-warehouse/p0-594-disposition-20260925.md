## 已查到的共用契約，不冒充共用原表

- 188 個比較統計圖層各有 indicator、期別、boundary version 和 releaseId。既有公開 statistics CDN `current.json` 指向 SHA-256 `8e4511ef…005f5efe` 的 2,448,038-byte manifest；188 層共 244 個 exact selectors 全部在 manifest。僅抽讀一個 artifact（SHA-256 `e140fe8b…18b5e2f`），其 source 內含分子、分母的 input SHA、授權、取得時間及缺值口徑，但 health 同時標 `publication_status=LOCAL_ONLY`。其餘 243 artifact 的 source/value/health 尚未逐一讀回，研究 reader 未註冊，故維持 `READER_PENDING`。[固定 CDN 收據](./p0-comparison-cdn-receipt-20260925.json)
- 209 個 `SOURCE_MISSING` 中，123 層雖能以同一 manifest `upstream.datasetId` 歸入 28 個宣告家族，仍缺相同 raw SHA 或同一 RPC schema/release 證據。例如畜牧場 7 層共用 `get_livestock_farms()`，但其 ARIS／NLSC／EMS／Google 是混合來源；衛星 16 層共用 `celestrak_satellites` DB contract，卻缺 immutable TLE snapshot；NCDR 告警 5 層共用 realtime table，但 CAP polygon、circle 與行政區補算的 geometry precision 不同。
- 209 層再按本機導航線索拆開：115 層有 exact `dataset_id` 的 analytics processed manifest 與同名 catalog；67 層只有 catalog；2 層有上游 ID 卻找不到上述同名檔；25 層連上游 ID 也沒有。processed 輸出、catalog 和 raw input／RPC receipt 是不同證據，故主狀態沒有因找到文件就放行。逐層 CSV 列出具體檔案路徑。
- 154 層只有 PMTiles/custom 等展示宣告；另檢視 21 個有 raw 家族線索的層，沒有一個能由本輪證據證明 raw→display 同版。機場本機檔和 analytics `airports_merged_20260215.geojson` SHA 不同；加油站來源 manifest 的「不做 Google geocode」文字與 `google_geocode_calls:307` 欄位相衝；都不能直接升格。

## 另列 105 個 metadata GeoJSON 候選

105 層宣告 96 個相異路徑；本 worktree 有 54 個實檔、42 個缺檔。逐檔 readback 的 54 個檔皆為有效 FeatureCollection，共 112,682,570 bytes、293,043 features、77 個 null geometry；幾何包含 Point、Polygon、MultiPolygon 和線，不能一律使用 Point reader。[逐檔 SHA／geometry／欄位缺值收據](./p0-geojson-readback-20260925.json)只證本機展示 payload，未證來源授權、觀測時間、完整母體、遠端版本或配對查詢。

## 邊界與下一步

本輪讓 594 層各有一個主狀態、具體 blocker、宣告契約／已核實 raw family 分欄與下一個所需證據；**並未找齊 594 層的原始資料，也未將它們標為可分析**。優先補 209 層的原表／RPC 身份，逐 release 核 188 個比較統計 artifact 的來源與 `LOCAL_ONLY` 矛盾，再對 154 個展示來源取得 input SHA 或產製 manifest。每個來源家族通過授權、時間、缺值、geometry、同版及有界 reader 後，才另片做 MCP/Gateway/browser 驗收。
