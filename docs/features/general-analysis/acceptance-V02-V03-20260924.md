## V03 有界能力與使用方式

三個predicate都走既有`spatial_query`／`pulse_run_analysis_plan`，不另開任意SQL、URL、程式碼或後端入口。每個input result必須完整恰好1feature；`limit`只是顯示頁大小，不能把多筆來源偷偷縮成單筆。

| 操作 | 必要參數 | 產物／語意 |
| --- | --- | --- |
| `line_buffer` | `resultId`, `radiusM` 1–500，可小數 | actual/derived eligible線的round環域，derived Polygon/MultiPolygon；不是步行或服務範圍 |
| `surface_intersection` | `leftResultId`, `rightResultId` | eligible actual/derived面的有面積交集；只有線／點接觸回空面，不聲稱拓樸完全不相交 |
| `measure_geometry` | `resultId` | 面積m²／線長m，無可呈現geometry；球面估計不是地籍／工程精度 |

給Agent的執行順序：

1. 確認live tool catalog支援predicate；已知descriptor不重複describe。檢查來源license/access、幾何role、時間與精度。
2. 用來源欄位篩選完整的單一feature。把query→buffer→intersection→measure放同一plan，透過step refs連接，避免手抄ID。必要的點位可再對derived面做既有within/intersects。
3. 若收到budget／geometry／authorization錯誤，說明尚未算出結果；改變問題範圍前保持來源語意。不得原樣重試、用display geometry頂替、截斷或自動修補。
4. 有幾何的結果先讀bounds，collection+framing只改一個revision；wait一次並讀map_context的實際renderedResultIds/features/source/layer/ready。再目視檢查圖例、遮蔽、顏色、互動。手動移圖後先讀新revision，不覆蓋舊狀態。
5. 報告使用的半徑、source version/未知時間、方法、限制；沒有路網就不能寫成可及性或服務人口。

Kernel：Turf 7.2.0，僅執行新predicate才dynamic import並註冊loadingRegistry；clear/revoke後不讓async結果復活。buffer為local azimuthal equidistant、16 arc steps（不是16位座標四捨五入）；intersection為EPSG:4326 planar clipping，面積與長度另標球面模型。readonly契約保留原始座標，沒有silently simplify。

範圍固定為本島周邊envelope `[119.5,21.8,122.1,25.5]`，單次combined input ≤1600 vertices、combined span ≤0.5°、output ≤8000 vertices/1MiB、topology comparisons ≤2,000,000。這是小範圍互動工具，非全臺任意Polygon運算；8000僅vertex ceiling，topology guard可能更早拒絕。

獨立來源與oracle詳見 [geometry spike](./geometry-spike-V03-20260924.md)：真實不同route UID的200m環域交集，Turf845,865.838m²，GEOS/EPSG:3826 845,938.627m²，差0.0086%；邊界長差0.0058%。原另一對routes的衍生頂點2091超過1600，保留為拒絕負例，未提高限制。holes、multipart、boundary-touch、空面、無效面、重複線點與超限有測試。這不證明第二個獨立主題面的資格，也不替代native browser验收。
