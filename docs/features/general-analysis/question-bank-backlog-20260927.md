# 問題庫題綱（2026-09-27，使用者提出＋擴充）

用途：把「想問但一時說不出來」的地理問題整理成可施工的題目。每題標出軸（空間／關聯／因果，見 geo-reasoning skill）、GIS 技法、需要的資料、目前狀態。落地後進 `mcp/src/warehouse/questionBank.ts`（回歸測試）與 `pulse-gis-analyst/references/recipes/`（配方）。

狀態：✅ 資料已在倉庫 ｜ 🟡 需補資料或小工具 ｜ 🔴 需新能力（等時圈、顯著性、即時資料）

## GIS 基礎技法對照（每題至少對應一種）

| 技法 | 用途 | 倉庫實作 |
|---|---|---|
| 環域（buffer） | 半徑內有什麼 | `ST_DWithin`／`ST_Buffer`（`geom_3826` 公尺） |
| 疊合（overlay：intersect／union／difference） | 兩層重疊的範圍與面積 | `ST_Intersection`、`ST_Area` |
| 點落面（point in polygon）、分區統計（zonal） | 每區有幾個、平均多少 | `ST_Within` + `GROUP BY` |
| 邊界交叉（line crossing） | 路線／河川穿越哪些區、跨越邊界的事件 | `ST_Intersects(line, boundary)`、`ST_Crosses` |
| 最近鄰（nearest） | 到最近 X 的距離分佈 | `ST_Distance` + `ORDER BY` |
| 密度／熱點 | 集中在哪 | 網格計數、核密度；顯著性 Gi*（🔴 待做） |
| 網路分析（等時圈、服務範圍） | 步行 10/15 分可到 | Valhalla（外部同意）或 osrm-taiwan（🔴 待接倉庫） |
| 相關與分層比較 | X 多的地方 Y 也多嗎 | `corr`，**必做縣市內分層**（辛普森悖論） |
| 相對比較（location quotient／百分位） | 某區在全市排第幾 | `percent_rank()`、z-score |
| 指數合成 | 生活品質指數等 | 多指標標準化＋權重＋敏感度（🔴 待做模板） |
| 時空序列 | 持續發生、前後變化 | 依週／月彙總、差異中的差異 |

## 一、基礎設施周邊關聯（空間＋關聯）

1. ✅ 發電廠／超高壓變電所周邊 1–3 km 有哪些重要設施（醫院、學校、消防、水利、交通樞紐）？哪些關鍵設施同時靠近多個能源設施？
2. ✅ 市場（批發／零售）與畜牧場的距離關係：供應半徑、縣市內分佈是否相依？
3. 🟡 擴充：加油站／液化石油氣 × 住宅密度；變電所 × 淹水潛勢（韌性）；水庫／淨水廠 × 污染源。

## 二、生活品質：面向拆解與相對比對（空間＋關聯，可成指數）

以「某區 vs 所屬市」「某里 vs 所屬區」的百分位呈現，而不是絕對數。

| 面向 | 指標 | 狀態 |
|---|---|---|
| 食 | 餐飲店家密度／熱度（核密度，每平方公里），區內百分位 | ✅（餐廳僅雙北基隆涵蓋，其他縣市標未涵蓋） |
| 衣 | 服飾零售（工商登記行業別） | 🟡 需行業分類對照 |
| 住 | 房價（買賣單價中位數）、租金、土地使用分區、超商密度 | ✅ 房價／公司；🟡 超商、分區需確認入倉 |
| 行 | 公車站數、路線數、班次、捷運站步行距離 | ✅ 站點／路線；🟡 班次；🔴 等時圈 |
| 育 | 國中小數、學區、師生比、補習班密度 | ✅ |
| 樂 | 公園綠地、運動場館、娛樂場所、宗教／文化設施 | ✅（公園涵蓋三市） |
| 環境與風險 | 淹水潛勢、噪音、毒化物、污染裁罰 | ✅ |
| 背景脈絡 | 人口、所得中位數、教育表現（拉大到區／市尺度） | ✅ 所得；🟡 人口 |

→ 產出「生活品質指數」：各面向標準化 → 權重（預設等權，可調）→ 區內／市內百分位；必附敏感度（換權重排名是否穩定）。

## 三、教育與運動資源可及性

1. 🔴 國小／國中步行 10、15 分涵蓋範圍（等時圈），找出覆蓋不足的里；與學區邊界疊合看錯位。
2. 🟡 運動可及性地圖：步行 15 分內可達網球場／匹克球場／羽球場的區域（需運動場館細分類欄位）；再疊熱度與地價（買賣或租金），看是否與高地價相關（縣市內分層）。

## 四、災害、環境與產業

1. ✅ 淹水潛勢 × 房價：潛勢區內外單價差，控制行政區（分層比較）。
2. 🟡 污染源 × 水源保護區（需確認保護區面資料）× 工商登記：周邊資本額低／設立短的企業、共同登記地址熱點。
3. ✅ 畜牧場空間分佈：最近鄰指數（集中／分散）、周邊土地使用、與水體距離。

## 五、新聞情勢與空間事件

1. ✅ 新聞熱點持續性：同鄉鎮連續多週出現重要事件（新聞座標為鄉鎮代理點，只做鄉鎮尺度）。
2. 🔴 邊界與地緣：中國海警船軌跡靠近領海／鄰接區的時段 × 同期台灣新聞（需船舶資料入倉與時間對齊）。
3. 🟡 地震震央周邊設施與環境（地震回放資料已有 RPC，需快照入倉）。

## 六、視覺化與跨區比較

1. ✅ 多縣市並排：教育資源、農業行為等統計圖層＋地圖同時呈現。
2. 🔴 雙變量地圖（兩指標 3×3）、多點比較面板、分級面量圖（見 PLAN-round3 軌道 3）。
