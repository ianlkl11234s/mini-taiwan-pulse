## 計次邊界

本表是20個情境，不等於已完成20次 warm 樣本。cold、需澄清、拒絕、來源故障、視覺操作分開計；速度報告須預先固定可完成的題組、開始/結束點及成功/partial/失敗分母，不以快速拒絕拉低成功題p95。量不到模型等待時填 unknown，不從總耗時臆測。新題可由測試者依合法來源範圍產生，不必要求使用者逐題提供；不得把本表情境寫進 runtime 路由。
