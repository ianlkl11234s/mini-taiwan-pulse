## E02 範圍與未過關原因

`tdx-road-events-current` 僅利用既有 `get_road_events_current`，不建新 DB/RPC。source allowlist 為 live_freeway/live_highway/live_city/event_city；eventType=1..8；unexpiredOnly 預設 true，對應 p_only_active。SQL 只排除 expire_time<=server now，保留 null expiry 與 future-effective；所以名稱/文案不宣稱 active-only。兩個有效完整時間才判 active/scheduled/expired，其他 unknown。acquiredAt 是判讀時刻，last_updated 是來源欄位，不能證明內容最近有變更。

`limit` 是輸出限制；event_type 與 time filters 是讀取後篩選，無法避開 source sentinel。縮資料要用 RPC parameters；下一階段需檢查 source current 清理/到期資料品質，及有明確完整性契約的時間/bbox/分頁 pushdown，不能單純放寬上限。此輪不修改遠端資料。
