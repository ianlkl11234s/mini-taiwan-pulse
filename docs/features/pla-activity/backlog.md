## PA-5 · 時間軸標示有資料的日期

`get_pla_track_dates()` 已經備好（回 day / shape_count / needs_review），
但前端時間軸目前沒有消費它 —— 使用者要自己撥到有資料的日子。
比照新聞事件的做法接上去可省掉盲撥。

## PA-6 · 回放的速度與暫停

目前回放是固定 18 秒一輪、無法暫停或拖曳到某一天。夠用但不精細。
若要更細的控制（速度選單、播放頭拖曳、停在特定日），值得考慮直接複用
`TimelineControls` 的互動模式，而不是在圖層參數裡再長一組。

## PA-7 · 疊加模式下的 popup 取捨

120 天疊加時同一點可能壓著十幾個形狀，目前 popup 只顯示最上層那一個。
若要看「這個位置歷來出現過幾次、哪幾天」，需要改成回傳該點命中的所有形狀清單。
