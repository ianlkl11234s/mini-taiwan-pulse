## PA-6 · 回放的速度與暫停

目前回放是固定 18 秒一輪、無法暫停或拖曳到某一天。夠用但不精細。
若要更細的控制（速度選單、播放頭拖曳、停在特定日），值得考慮直接複用
`TimelineControls` 的互動模式，而不是在圖層參數裡再長一組。

## PA-7 · 疊加模式下的 popup 取捨

若要看「這個位置歷來出現過幾次、哪幾天」，需要改成回傳該點命中的所有形狀清單。

## PA-8 · 兩個已定位但未修的解析缺口（2026-08-03 盤點，owner 決定先不改）

全期 730 天現況：**架次 0 缺**、越線缺 1、共艦缺 7、統計窗缺 1。
**近 120 天解析失敗 0 天** —— 戰情板的「灰=解析失敗」柱目前不會出現，那是防禦性設計。

### 可修（兩個小改，都在 `data-collectors/collectors/pla_activity_daily.py`）

1. **日期正則把 `0600` 寫死** → 演習日抓不到統計窗
   2024-10-14 聯合利劍-2024B（153 架次、越線 111，全期最高）原文是
   「113年10月14日（星期一）**0500時**至10月15日…」，國防部為框列演習架次自行改了起算時間。
   `_RE_PERIOD` 的 `0600\s*時至` 不匹配 → period_end 落空。
   **偏偏是全期最重大的一天漏欄位。** 改法：`0600` → `\d{4}`。

2. **「未偵獲共機、艦」時共艦沒記 0**
   7 筆缺共艦裡有 6 筆是這句型。架次已正確記 0（前一輪修的 11 個 bug 之一），
   但同一句的共艦漏掉推斷 → 留 NULL。原文既已明說「未偵獲」，應記 0。

改完需重跑回填才會套用到歷史（`scripts/backfill_pla_activity.py --resume`）。

### 不該修（留 NULL 是正確的）

- **2025-03-29 缺越線**：「偵獲共機1架次（逾越海峽中線進入西南空域）」括號裡沒放數字。
  語意上推得出是 1，但解析器不猜 —— 寧可標未知也不要編數字。
- **2024-10-30 缺共艦**：「偵獲共機8架次(其中進入西南空域4架次)，在臺海周邊活動。」
  整句沒提共艦。「沒提」≠「0 艘」。
