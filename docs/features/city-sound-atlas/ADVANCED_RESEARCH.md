# ADVANCED_RESEARCH — 建物遮蔽、聲學模型與校準（研究文件，不實作 dB）

> W5（2026-11-11）。對應計畫 §6.3、§10 Phase 5、§14 聲學參考。
> 本文只做研究與計畫：**目前所有輸出仍是無單位 0–1 的相對潛勢**，`modeledDbA` 型別固定為 `null`。
> 外部工具與方法的描述來自其公開文件的一般知識，**本次沒有實際安裝或跑過 NoiseModelling**；要用前請以當次官方文件為準。

## 1. 四種產品語意（任何 UI／API 都要標清楚是哪一種）

| 語意 | 定義 | 單位 | 本專案現況 | 可以說 | 不可以說 |
|---|---|---|---|---|---|
| `source_activity` | 某來源「此刻是否在活動」的證據（航機在 20 km 內、許可期間內、浪高 3 m） | 布林／類別＋證據等級 | 已有（各 adapter 的 status＋evidence） | 「此刻有航機在附近」「施工許可期間內」 | 「聽得到」 |
| `relative_potential` | 同一家族內、無單位 0–1 的活躍潛勢（距離衰減＋強度 proxy） | 無 | **已有（目前唯一的數值輸出）** | 「相對潛勢較高」「主要接觸飛機與雨」 | 「X 分貝」「比較吵」（跨家族不可比） |
| `modeled_LAeq` | 依物理聲學模型（排放×傳播）算出的 A 加權等效連續音量 | dB(A)，須註明時段（LAeq,1h、Lden…） | **無**（gate 未過） | 只有通過 §4 gate 後才可說「模型估計約 X dB(A)」 | 未校準前任何 dB 數字 |
| `measured_LAeq` | 實際儀器量到的 LAeq | dB(A)，須註明測站、儀器等級、時段 | 無（未接任何噪音測站） | 「某測站某時段量到 X dB(A)」 | 把單點量測外推成整區 |

規則：
1. 四種語意在型別上分開欄位，不共用一個 `value`。`relative_potential` 不能被後續程式改名成 dB。
2. 跨家族不加總：`relative_potential` 各家族的尺度不同（飛機 2 km 半衰、雨 10 mm/h 尺度），相加沒有物理意義。要合成只能在 `modeled_LAeq` 層用能量合成 `10·log10(Σ 10^(L_i/10))`，且各 `L_i` 必須同指標、同時段、同校準來源。
3. LAeq、Lmax、L10、峰值不可混用；proxy（浪高、風速、水位分位）不是任何一種。

## 2. 建物遮蔽：為什麼不能二分「有建物擋＝0」

1. **繞射**：聲波波長（100 Hz ≈ 3.4 m、1 kHz ≈ 0.34 m）與建物尺度相近，會繞過屋頂與牆角；低頻（車流、飛機、雷聲的主要能量）繞射最強。屏障衰減在 ISO 9613-2 等方法裡是有上限的（單一屏障約 20 dB、雙重約 25 dB 量級），不是無限大。
2. **反射**：街谷（兩側高樓）會把聲音來回反射，接收點可能比空曠處更大聲；「看不到聲源」也可能聽到反射聲。
3. **地面效應與地形**：軟地面（草地）吸收、硬地面（柏油）反射；地形起伏本身就是屏障。
4. **氣象折射**：順風、逆溫會把聲音往下彎，越過屏障；逆風則形成陰影區。距離越遠影響越大（飛機、雷聲、海浪都是遠距聲源）。
5. **聲源高度**：飛機在數百公尺高空，地面建物對它幾乎不構成遮蔽；鐵道高架段的輪軌聲在 8–15 m 高，比地面車流更不受低矮建物影響。
6. **資料不夠**：Pulse 有建物輪廓（buildings_value_taiwan.pmtiles）但樓高、門窗、外牆材質不完整，二分法會把資料缺口包裝成「安靜」，違反「unknown 不是 0」。

結論：遮蔽只能以**連續的插入損失（dB）**在物理模型裡處理；在相對潛勢層不做任何遮蔽係數，接收者若在室內一律維持 `indoor_unknown`。

## 3. NoiseModelling／CNOSSOS-EU 可行性

| 面向 | 評估 |
|---|---|
| 是什麼 | NoiseModelling（法國 Université Gustave Eiffel 等開發，GPL）是開源的環境噪音地圖工具，實作 CNOSSOS-EU（歐盟環境噪音指令 2002/49/EC 指定的共通評估方法）的道路、鐵道、工業排放與傳播（含繞射、反射、地面效應、氣象條件）。以 H2GIS／PostGIS 為底、Groovy／WPS 腳本操作。 |
| 適用聲源 | 道路車流、鐵道、工業點源最成熟；航空在 CNOSSOS 有方法但需航跡＋機型性能資料（同 FAA AEDT 的 ANP 類資料），本專案沒有可用的機型聲學參數。雨、雷、海浪、風、河川**不在** CNOSSOS 範圍。 |
| 需要的輸入 | 道路：車道幾何、各車種逐時流量與車速、路面類型、坡度；鐵道：列車種類與班次、軌道結構；建物：輪廓＋高度；地形 DEM；地面類型（G 係數）；接收點。 |
| 本專案缺口 | (1) 市區道路沒有車流量（只有國道 VD、雙北部分 VD），T01 目前只有道路類型 proxy；(2) 建物高度只有部分縣市可信；(3) 車種組成與車速逐路段不全；(4) 台灣沒有 CNOSSOS 參數本地化（車種排放係數以歐洲車隊為準）。 |
| 運算成本 | 城市尺度網格計算是批次工作（分鐘到小時），**不適合**前端即時；只能做 analytics 側的離線情境（類似 ADR-0025 sim_bundle），前端只顯示結果。 |
| 建議 | 不作為 v1。若要做，先選**一個**有 VD 流量與可信建物高度的小區（例：臺北某主要幹道兩側 1 km），用 NoiseModelling 算 LAeq,1h，與 §4 的校準集比對；通過才談擴大。 |

## 4. 校準資料與「校準集／驗證集分開」計畫

### 4.1 候選量測來源（都**未實測**，上線前要查授權與欄位）

| 來源 | 內容 | 注意 |
|---|---|---|
| 環境部噪音監測（一般地區／道路交通噪音監測站） | 固定站，LAeq 與日夜時段值 | 站點稀疏、多為時段統計值而非逐時；授權待查 |
| 機場周邊航空噪音監測站（民航局／機場公司） | 機場周邊固定站，Ldn／單一事件 | 只涵蓋機場周邊，最適合校準 A01；資料是否公開、粒度待查 |
| 交通部高鐵／台鐵噪音監測（環評追蹤） | 環評監測報告，多為 PDF | 非逐時開放資料，只能當少量參考點 |
| NoiseCapture（Université Gustave Eiffel，手機 App 公民量測，ODbL） | 世界各地的手機量測軌跡與 LAeq | 手機麥克風未校準、使用者行為偏差、時間窗短；只能當**相對**驗證或質性參考，不可當絕對 dB 真值 |
| 自行量測（Class 1／2 噪音計） | 可控時段與地點 | 成本高；要記錄儀器、校正器、氣象、量測高度 |

### 4.2 分組原則

1. **測站層級分組**：以「測站」為單位隨機分成校準集（約 60–70%）與驗證集（約 30–40%）；同一測站的不同日期**不可**同時出現在兩組（避免時間自相關造成假性準確）。
2. **時間外推另驗**：額外保留最近一段期間（例：最後一個月）只做驗證，檢查參數是否隨季節漂移。
3. **事件分層**：颱風、雷雨等極端日另列，不混在一般日的誤差統計裡。
4. **先凍結再驗證**：校準完成後凍結參數、升 `MODEL_VERSION`（major），再跑驗證集；驗證失敗不得回頭用驗證集調參。
5. **通過門檻（gate）先寫死再看結果**：例如驗證集 LAeq,1h 的 RMSE ≤ 3 dB 且系統偏差 |bias| ≤ 2 dB；未達門檻 → `modeledDbA` 維持 `null`，UI 不顯示任何 dB。
6. **紀錄**：參數、資料版本、分組名單、門檻、結果都進 `MODEL_DECISIONS.md` 與版本號；文獻參數保留 DOI／方法版本，設計假設標 assumption，不包裝成「研究證明」。

### 4.3 相對潛勢本身的「弱驗證」（不需要 dB）

在沒有 dB gate 之前，可以只驗**排序**：同一測站、同一時段，相對潛勢高的時段是否對應量測 LAeq 較高（Spearman 相關、命中率）。這只能說「排序有參考價值」，不能把潛勢換算成 dB。

## 5. 雨打材質 N06（只做研究，不實作）

- 同一場雨，打在鐵皮屋頂、混凝土、樹冠、水面的聲音差異很大，但 Pulse **沒有屋頂材質資料**；建物圖層只有輪廓與部分屬性，沒有屋面材料。
- 依計畫：**屋頂材質未知一律 `roof_unknown`，不臆造鐵皮**。航照影像辨識鐵皮屋（vision-osint skill 的範疇）屬於推論資料，要另行驗證精度與授權後才能當 `inferred` 證據。
- 樹冠部分可沿用 W5 的樹冠格網（同 N03）。若日後要做，建議在 `SourceContribution` 加可選 `surfaceContext: { roof: "roof_unknown" | ...; canopyCover: number | null }`，預設 `roof_unknown`，**不改雨的相對潛勢**，只在面板文字說明「此處材質未知」。本版沒有加這個欄位（避免 UI 先出現一個永遠 unknown 的欄位）。
- 雨聲遮蔽（masking）同理：只能做「其他聲源可察覺性」的獨立研究指標，不從其他家族的潛勢扣除。
