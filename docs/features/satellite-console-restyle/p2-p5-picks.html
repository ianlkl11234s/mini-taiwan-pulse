衛星情報面板 P2–P5 比較

這頁一次把 P2（群組列）、P3（台灣衛星隊＋覆蓋統計）、P4（變軌警報、對比彈窗、百科卡、地圖 popup）、P5（淡色版）的選擇做完。每題先放「現況」，再放 2–3 個選項，每個選項暗色與淡色並排。示意面板都建立在 P1 已實作的標頭、區段標題、footer 上，值取自站上實際 token；顆數與時間為示意。

點選項卡片就是選它（再點一次取消，也可用鍵盤 Enter／空白鍵）。標「建議」的是建議組合；按底部「全部採用建議」會把還沒選的題目填成建議，已選的不動。標「⚠ 改共用元件」的選項會動到其他面板也在用的元件。

淡色欄在 P5 實作前只是示意：P2–P4 先照暗色做，淡色欄用來確認選的樣式到淡色時也撐得住。最上方先確認 P1 的三個細節。選完按「複製答案」貼回來；複製失敗就用頁面最下方的文字框。選擇會存在這個瀏覽器裡，重新整理不會消失。
