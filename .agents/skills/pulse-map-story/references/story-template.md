# 故事腳本模板

這是 Agent 的故事工作稿，不是目前網站可直接載入的檔案格式。先完成所有章節，再開始呈現。僅保存查得的值；未查到寫「未知」，不填虛構數字。每章共享相同的比較口徑。

## 故事

- 故事 ID 與檔案路徑：
- 題目：
- 想回答的小問題：
- 候選比較角度（2–3 個，各一句）：
- 採用的主要比較軸與理由：
- 對照對象、選取依據、地理範圍：
- 時間口徑（資料年份／觀察時間／歷史背景分開）：
- 核心觀察（有證據才寫；否則寫待檢視問題）：
- 播放方式：手動／本回合自動；每章閱讀時間：
- 起點：原有圖層 overrides、鏡頭、時間模式、已讀取且會修改的控制項；不含憑證。
- 進度：準備中／已備妥／導覽中／暫停／完成；最後完成章節：

## 來源清單

| ID | 名稱、網址或站內 layer key | 時間與覆蓋 | 取得方式與證據層級 | 支持什麼／不能支持什麼 |
|---|---|---|---|---|

證據層級使用：目錄說明／已觀察資料或畫面／外部背景／推測。layer key 必須來自本次工具結果；外部資料不代表已接進地圖。

## 章節（每章複製本段）

- 章次與標題：
- 本章回答的問題、承接上一章的關係：
- 講解正文（約 100–180 字，包含觀察與有來源的補述）：
- 看圖提示（一句，告訴使用者看哪個位置或特徵）：
- 支持此段的來源 ID：
- 圖層：保留／開啟／只關閉本故事已新增的項目。
- 控制項：controlId、目標值；expectedValue 執行前才讀，不把腳本中的舊值直接送出。
- 時間：保持原狀，或 live／replay＋已確認日期時間（Asia/Taipei）；來源與覆蓋。
- 鏡頭：已核對的 bounds＋來源；或單點 center＋zoom＋定位依據。執行由網站避開面板。
- 可比較性：同來源、單位、期間、範圍；不一致時如何限制敘述。
- 執行紀錄：待呈現／已呈現／部分可用／未完成；最後回執與實際載入狀態。
- 資料不可用時：哪段仍可說明、哪個結論必須刪除；不自動假設為零。

- 有來源的背景解釋；沒有證據的原因明確保留：
- 值得下一次探索的問題：
