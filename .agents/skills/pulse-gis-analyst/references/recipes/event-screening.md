# 事件周邊敏感設施篩查（空間）

**適用**：「這些新聞事件周圍有沒有學校／托嬰／長照」「事件點附近有什麼敏感機構」。

**工具鏈**
- 單一或少量事件（≤5）：`pulse_nearby_profile({points, radiusM: 300–500, categories:["sensitive_facility"]})`。
- 批次事件（倉庫有事件表時）：`pulse_sql`，事件表 × 敏感設施表以 `ST_DWithin(e.geom_3826, f.geom_3826, R)` 做 join，回每個事件的命中數與最近距離，`ORDER BY` 命中數。
- 敏感設施集合以 `categories.json` 的 `sensitive_facility` 為準（學校、幼兒園、托嬰、兒少、課照、老人住宿、護理、長照、身障、醫療）。

**必帶但書**：命中只代表「在半徑內」，不代表受影響；事件座標常是地址或行政區代理點，說明精度；新聞事件時間與設施資料時間不同。

**停止**：命中事件清單（前 10）＋總數；不逐筆描述未命中者。

**追問**：命中最多的事件要不要放大看？要不要只看兒少類設施？要不要改成「事件 → 最近設施距離」分佈？
