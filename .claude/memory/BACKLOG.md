## Operating rules

- **Priority** orders work that is actionable now: `P0` urgent release/incident, `P1` current planning window, `P2` planned, `P3` opportunistic. A date- or upstream-gated item is not P0 merely because it matters later.
- **State** is separate from priority and is only one of: `ready`, `in_progress`, `blocked`, `waiting_external`, `conditional`, `verifying`.
- Each active item has one primary home. Do not duplicate a feature item here: use the feature index and its canonical link instead.
- `Acceptance / evidence` is the condition for closing an item; `last verified` is an observation date, not proof of production release.
